This Adobe After Effects script automates the composition background setup. It disables the Transparency Grid across the compositions and applies a predefined background color, making it easier to work with a consistent visual background during editing and preview.

The script is useful when working with multiple compositions where the Transparency Grid needs to be turned off manually. Instead of changing each composition individually, the script applies the settings automatically, saving time and reducing repetitive work.

To use the script, open the .jsx file and define your preferred background color in the script if required. Run the script from Adobe After Effects, and it will process the compositions and apply the specified background settings.”
